# Электрокомплект — frontend

Одностраничное визуальное демо по референсу: React, strict TypeScript, Tailwind CSS, Recharts.

## Запуск
Node.js 20.19+ или 22.12+.
```sh
cd frontend
npm install
npm run dev
```
Откройте адрес из терминала. Проверка: `npm run build`.

## Что работает
Поиск по товару, артикулу и поставщику; фильтры; выбор строк; сортировка;
раскрытие объяснений; группировка таблицы по поставщикам; CSV выбранных
или отфильтрованных строк; графики по реально отображаемому демо-набору.

## Граница демо
docs/API_CONTRACT.md пуст на момент реализации. src/types/demo.ts — только
тип представления, НЕ контракт сервера. src/mocks/demo.json — один визуальный
набор из пяти позиций по референсу, НЕ контрактный mock.
src/types/api.ts намеренно не содержит выдуманных API-полей.

VITE_API_MODE=mock (по умолчанию) загружает пример через src/api/client.ts.
Любое другое значение показывает явную ошибку, без скрытого отката на mock.
После согласования API типы и адаптер добавляются в этой единой точке.

recommended не вычисляется frontend. Численные коэффициенты, прогноз спроса,
what-if POST, история Agent Run и утверждение заказов не имитируются.
Разъяснения аномалии и stockout отмечены как примеры. Разные единицы не суммируются.
Экспорт CSV — локальная выгрузка рекомендаций, не отправка поставщику.
График показывает заданный заказ и остаток в штуках, не вымышленный прогноз.
