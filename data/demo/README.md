# Учебный набор для интеграционного прогона

Это **синтетические**, а не реальные продажи партнёра. Шесть SKU и идентификаторы
поставщиков взяты из demo backend-ветки; история расширена для воспроизводимого
прогона интерфейс → API → алгоритм → SQLite.

56 календарных дней: 2026-07-29 — 2026-09-22. Все количества в базовых единицах.
Поставщики, остатки и сроки поставки сохранены из исходного backend demo.

- STABLE-001: стабильный спрос 10–12 единиц.
- SEASON-001: повторяющийся недельный рисунок (выходные выше будней).
- GROW-001: каждые 14 дней базовый спрос растёт на две единицы.
- STOCKOUT-001: 15–17 сентября продажи нулевые, отсутствие отмечено отдельно.
- BULK-001: 18 сентября разовая продажа 500 единиц.
- TRANSIT-001: 100 единиц в пути с датой 25 сентября.

API получает результат настоящего алгоритма. Никакие готовые рекомендации
из frontend mock в вычислении не участвуют. Локальная сезонная эвристика MVP
не является годовой моделью сезонности; клиентского анализа транзакций в этом
агрегированном CSV нет.
